Projects

Here are some of my academic and practical projects that reflect my growing interest in cybersecurity, networking, and compliance.

Wireshark Traffic Analysis Lab

Captured DNS, HTTP, and TCP packets using Wireshark. Analyzed network traffic to identify protocols, requests, and communication patterns. Investigated suspicious traffic and documented findings.

Tools: Wireshark, Network Analysis, Packet Capture

SOC Home Lab

Built a basic SOC lab using VirtualBox with Windows and Linux virtual machines. Practiced log monitoring, alert investigation, and incident triage using Splunk and Windows Event Logs. Investigated authentication events, failed login attempts, and basic security alerts to understand SOC workflows. Documented incident findings and followed basic incident response procedures.

Tools: VirtualBox, Splunk, Windows Event Logs, SOC Practices

ISO 27001 Compliance Tracker

Created an ISO 27001 compliance tracker using Microsoft Excel and Google Sheets to organize audit evidence. Reviewed security documentation and mapped compliance requirements against implemented controls. Assisted in maintaining audit-ready documentation and tracking compliance status.

Tools: Microsoft Excel, Google Sheets, Compliance Tracking
