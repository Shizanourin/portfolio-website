# Portfolio Website

A personal portfolio website built with HTML and CSS to showcase Shiza's skills, projects, and contact information. The site is designed with a clean modern aesthetic, responsive layout, and consistent navigation across pages.

## Project Overview

This website serves as a professional portfolio for an aspiring cybersecurity professional. It highlights relevant projects, provides a polished contact page, and uses a welcoming hero section to introduce the user.

## Key Pages

- `index.html` — Hero landing section with profile image, introduction, and a call-to-action button.
- `projects.html` — Project showcase with visually styled cards, hover effects, and project summaries that emphasize cybersecurity, networking, and compliance work.
- `contact.html` — Contact page styled to match `projects.html`, with hoverable contact cards and modern page layout.
- `about.html` — Additional page for personal background and skill details (if present).

## Features

- Clean neutral color palette with blue accents
- Hover effects for navigation links and content cards
- Consistent card and container styles for professional presentation
- Simple modular layout using plain HTML and embedded CSS

## Technologies

- HTML5
- CSS3

## Notes

- The current website is designed for a small static portfolio and can be extended with additional pages or JavaScript enhancements.
- Local image assets are stored in the project folder and referenced using relative paths.

## How to Use

1. Open `index.html` in a browser to view the homepage.
2. Navigate to `projects.html` and `contact.html` for project details and contact information.
3. Update content directly in the HTML files to customize text and links.
